Quickstart & Client Integrations

Because CIVORA implements the OpenAI v1 specification, you can drop CIVORA directly into your existing OpenAI SDK setup.

from openai import OpenAI

client = OpenAI(
    api_key="civora_sk_live_YOUR_KEY_HERE",
    base_url="http://localhost:4000/v1"  # Or your CIVORA deployed domain
)

# 1. Non-streaming call
response = client.chat.completions.create(
    model="civora-coder",
    messages=[
        {"role": "system", "content": "You are CIVORA Principal Software Engineer."},
        {"role": "user", "content": "Explain and optimize this Python algorithm."}
    ],
    temperature=0.7,
)
print(response.choices[0].message.content)

# 2. Real-time streaming call
stream = client.chat.completions.create(
    model="civora-repository-agent",
    messages=[{"role": "user", "content": "Analyze repository drift"}],
    stream=True,
)
for chunk in stream:
    if chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
                    
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.CIVORA_API_KEY || "civora_sk_live_YOUR_KEY_HERE",
  baseURL: "http://localhost:4000/v1"
});

async function main() {
  const response = await client.chat.completions.create({
    model: "civora-coder",
    messages: [
      { role: "user", content: "Write a high-throughput Node.js microservice handler." }
    ]
  });

  console.log(response.choices[0].message.content);
}

main().catch(console.error);
                    
import OpenAI from "openai";

const client = new OpenAI({
  apiKey: process.env.CIVORA_API_KEY || "civora_sk_live_YOUR_KEY_HERE",
  baseURL: "http://localhost:4000/v1"
});

interface EngineeringReply {
  content: string;
  model: string;
}

async function requestCivora(prompt: string): Promise {
  const res = await client.chat.completions.create({
    model: "civora-engineering-agent",
    messages: [{ role: "user", content: prompt }]
  });
  return res.choices[0].message.content ?? "";
}

Connect CIVORA to Cursor & VS Code

Configure your favorite AI-powered coding editor to use CIVORA as its primary intelligence engine.

Cursor IDE Configuration

Point Cursor to CIVORA's OpenAI-compatible endpoint

  1. Open Cursor Settings (Cmd + , or Ctrl + ,).
  2. Navigate to Models tab.
  3. Toggle OpenAI API Key and enter your civora_sk_live_... key.
  4. Toggle Override OpenAI Base URL and enter:
http://localhost:4000/v1

Add custom model name civora-coder or civora-engineering-agent to the active models list.

VS Code Continue / Cline Extension

Configure inside ~/.continue/config.json

{
  "models": [
    {
      "title": "CIVORA Coder",
      "provider": "openai",
      "model": "civora-coder",
      "apiKey": "civora_sk_live_...",
      "apiBase": "http://localhost:4000/v1"
    }
  ]
}

Restart VS Code. CIVORA will power your code completions, refactorings, and inline audits.
